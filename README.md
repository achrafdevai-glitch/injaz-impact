# إنجاز | INJAZ — منصة إنجاز الأثر

> خطوة منك… أثر في مجتمعك.

منصة جزائرية للتطوع، تجمع اكتشاف المبادرات حسب الولاية، المشاركة في التحديات، متابعة الأثر، والتسجيل ببيانات المتطوع. واجهتها عربية باتجاه من اليمين إلى اليسار، مع الفرنسية والإنجليزية، وتصميم زجاجي وتطبيق ويب قابل للتثبيت (PWA).

## 1. الحالة الحالية: ما الحقيقي وما التجريبي؟

**هذا شرح للتنفيذ الموجود، وليس ضمانًا بأن التطبيق جاهز للإنتاج أو يعمل بنسبة 100%.**

- **متصل بـLovable Cloud:** إنشاء الحساب والدخول، حفظ وتعديل بيانات تسجيل المتطوع، رفع صورة بطاقة الهوية إلى مساحة خاصة، وحذف بيانات التسجيل. الفحص بالذكاء الاصطناعي يستخدم AI Gateway.
- **ما يزال تجريبيًا ومحليًا:** التحديات، المشاركات وإثباتات الأثر، النقاط، ساعات التطوع، المستويات، الأوسمة، المتصدرون، المكافآت، وشاشة الإشراف. بياناتها الأولية جاهزة داخل التطبيق والتغييرات محفوظة في متصفح المستخدم، وليست سجلًا مشتركًا بين المتطوعين.
- تسجيل المتطوع الحقيقي لا يستبدل تلقائيًا كل معلومات الحساب التجريبية المعروضة في بقية الصفحات.
- لم يُثبت اختبار كامل بحساب حقيقي وصورة بطاقة أن دورة الفحص والحفظ والحذف تعمل من البداية إلى النهاية. يلزم ذلك قبل استعمال بيانات هوية حقيقية على نطاق واسع.

## 2. بدء الاستخدام والتنقل

عند الدخول لأول مرة تظهر ثلاث شاشات ترحيبية. يمكن تخطيها أو الانتقال منها إلى إنشاء حساب. يتذكر المتصفح إكمال الترحيب؛ مسح بياناته أو استخدام متصفح آخر قد يعيد عرضه.

التنقل الأساسي عبر شريط زجاجي سفلي عائم بخمس وجهات: **الرئيسية، التحديات، خريطة الأثر، المتصدرون، حسابي**. التصميم الحالي يتضمن التجويف والدائرة الخضراء المرتفعة للوجهة النشطة. لا توجد قائمة همبرغر أو قائمة جانبية أو درج تنقل. تغيير اللغة موجود داخل الإعدادات فقط.

## 3. الصفحات ووظائفها

| الصفحة | المسار | عملها |
| --- | --- | --- |
| الرئيسية | `/` | بطاقة رصيد الأثر، مؤشرات الساعات والمبادرات والترتيب، تحديات مميزة، واختصارات للتحديات والخريطة والمكافآت والإشراف. الأرقام الحالية تجريبية. |
| الترحيب | `/onboarding` | تقديم المنصة عبر ثلاث شرائح، مع التخطي والانتقال للتسجيل. |
| الدخول وإنشاء الحساب | `/auth` | إنشاء حساب أو الدخول بالبريد وكلمة المرور، مع خيارات الدخول الاجتماعي الموجودة في الصفحة. عمل كل مزود وتأكيد البريد يتوقف على إعدادات الخدمة الفعلية. |
| تسجيل المتطوع | `/register` | إدخال البيانات، اختيار صورة البطاقة، طلب الفحص، مراجعة النتيجة، ثم تأكيد الحفظ في الحساب. يتطلب تسجيل الدخول. |
| التحديات | `/challenges` | عرض الكل أو المنضم إليها، البحث والتصفية حسب التصنيف، مشاهدة تفاصيل التحدي، الانضمام وإرسال وصف لإثبات المشاركة. |
| خريطة الأثر | `/map` | خريطة تفاعلية للجزائر و58 ولاية، اختيار ولاية، عرض المبادرات والإحصاءات، التكبير والتحريك والفلاتر والاكتشاف وأدوات الموقع. |
| المتصدرون | `/leaderboard` | المراكز الثلاثة الأولى وقائمة الترتيب، وطنيًا أو على مستوى الولاية؛ القائمة الحالية تجريبية. |
| حسابي | `/profile` | الصورة الحالية، المستوى، الفئة، الساعات، عدد المبادرات، الترتيب، تقدم XP، الأوسمة وسجل المساهمات، مع الوصول إلى الإعدادات. |
| المكافآت | `/rewards` | تبويبات اكتساب النقاط واستعمالها والامتيازات، وكتالوج لاستبدال الرصيد؛ لا يمثل حاليًا تسليم مكافآت فعلية. |
| الإعدادات | `/settings` | اللغة، الوضع الليلي، تثبيت التطبيق، إعادة ضبط البيانات المحلية، شرح خصوصية التسجيل، تعديل التسجيل وطلب حذف بياناته. |
| الإشراف | `/admin` | مراجعة الإثباتات بقبولها أو رفضها، مع نظرة على التحديات؛ شاشة تجريبية وليست نظام صلاحيات إشراف إنتاجي. |

## 4. التسجيل الحقيقي خطوة بخطوة

1. أنشئ حسابًا أو سجّل الدخول من صفحة الحسابات. إذا طلبت الخدمة تأكيد البريد، أكمله قبل متابعة التسجيل.
2. افتح صفحة تسجيل المتطوع واملأ: **الاسم، اللقب، رقم الهاتف، الجنس، المستوى التعليمي، طبيعة العمل، أيام الفراغ، الولاية والبلدية**.
3. أرفق صورة البطاقة الوطنية. يقبل حقل الرفع الصور، ويحوّلها التطبيق إلى JPEG مع تصغير أكبر ضلع إلى 1600 بكسل عند الحاجة.
4. اختر يوم فراغ واحدًا على الأقل. حقل الهاتف يقبل رقمًا جزائريًا من عشرة أرقام يبدأ بـ05 أو 06 أو 07. البلدية تُكتب يدويًا؛ لا توجد قائمة بلديات مترابطة حاليًا.
5. اضغط **«فحص البيانات والبطاقة»** ثم راجع النتائج الظاهرة.
6. عدّل البيانات أو أعد التصوير إذا لزم. اضغط **«تأكيد وحفظ»** بعد المراجعة.
7. تُرفع الصورة إلى مساحة `id-cards` الخاصة داخل مجلد حسابك، ثم تُحفظ البيانات ونتيجة المراجعة في `volunteer_registrations`. التسجيل مرتبط بحساب واحد ويُحدّث عند إعادة الحفظ.
8. بعد النجاح ينتقل التطبيق إلى الرئيسية. عند فتح التسجيل مجددًا تُسترجع البيانات المحفوظة؛ الصورة السابقة لا تُعرض تلقائيًا، ويلزم اختيار صورة للفحص والحفظ الجديد.

## 5. فحص البطاقة بواسطة AI Gateway

الفحص يستدعي وظيفة خادم تتطلب حسابًا مسجلًا، ويرسل صورة البطاقة والبيانات المدخلة إلى نموذج عبر **AI Gateway**. يطلب من النموذج:

- فحص الحقول الفارغة أو غير الصحيحة بوضوح.
- استخراج الاسم واللقب وتاريخ الميلاد ورقم البطاقة، وترك غير المقروء فارغًا.
- بيان اختلاف الاسم واللقب بين الصورة والنموذج.
- تحديد قابلية قراءة الصورة واكتمال البيانات.

تعرض الصفحة الحقول المستخرجة والنواقص والاختلافات قبل الحفظ. ليست هذه مصادقة حكومية ولا فحص تزوير ولا إثباتًا قانونيًا للهوية؛ قد يخطئ النموذج، والمراجعة البشرية ضرورية.

**حدود التنفيذ الحالي:** زر الحفظ يمنع الحفظ عند اعتبار الصورة غير مقروءة، لكنه لا يمنعه تلقائيًا لمجرد وجود اختلافات أو نتيجة عدم اكتمال. لذلك لا يُعد الفحص ضمانًا صارمًا لصحة التسجيل. إعادة الفحص ترسل البيانات مرة أخرى وقد تستهلك رصيدًا إضافيًا. تظهر رسائل عند نفاد الرصيد أو ضغط الطلبات أو تعذر قراءة الصورة.

## 6. الخصوصية والحذف

بيانات التسجيل وصورة البطاقة مقصود أن تكونا خاصتين بصاحب الحساب، وليستا جزءًا من الترتيب العام. يلزم التحقق عمليًا من سياسات الوصول قبل الإطلاق. لا تتضمن هذه الوثيقة كلمات مرور أو مفاتيح خدمات.

من الإعدادات، **«تعديل بيانات التسجيل»** يفتح النموذج، و**«طلب حذف بياناتي»** يطلب تأكيدًا ثم يسجل طلبًا في `deletion_requests` ويحاول إزالة الصورة وحذف سجل التسجيل مباشرة.

- هذا الإجراء لا يحذف حساب الدخول نفسه ولا سجل طلب الحذف ولا كل البيانات المحلية تلقائيًا.
- إعادة ضبط البيانات المحلية منفصلة عن حذف التسجيل المحفوظ.
- التنفيذ الحالي لا يتحقق من أخطاء تسجيل طلب الحذف وإزالة الصورة مثل تحققه من حذف سجل التسجيل؛ رسالة النجاح وحدها لا تثبت إزالة كل الملفات.
- لا يوجد في التنفيذ الموثق جدول آلي للاحتفاظ أو حذف النسخ الاحتياطية، ولا ضمان موثق لحذف بيانات أُرسلت إلى مزود الذكاء الاصطناعي. يلزم تحديد هذه السياسة والتحقق منها قبل معالجة بطاقات حقيقية على نطاق واسع.

## 7. خريطة الأثر وصور الولايات

الشاشة تحافظ على تكوين مرجع CityRoute AR: خلفية شارع، إحصاءات زجاجية عائمة، مسار بصري فوق المشهد، خريطة سفلية منحنية وأدوات اكتشاف وموقع.

اختيار الولاية يغير الصورة العلوية إلى الصورة المرتبطة بها من مجموعة الصور المحفوظة محليًا، بدل طلب صورة من ويكيبيديا أثناء الاستخدام. عند غياب صورة تظهر الخلفية الاحتياطية. الخريطة تعرض 58 ولاية، لكن وجود ولاية في القائمة لا يعني أن لها صورة مستقلة متحققة؛ لم تُراجع مطابقة الصور ومصادرها وحقوقها جميعًا. لا تُعد الخلفية أو مسار AR ملاحة حقيقية أو بث كاميرا مباشرًا.

أدوات الموقع تحتاج إذن المتصفح، وقد تتعذر إذا رفض المستخدم الإذن أو لم تتوفر خدمة تحديد الموقع. المبادرات والإحصاءات المعروضة ما تزال مرتبطة بالبيانات التجريبية.

## 8. المشاركة والتلعيب والمكافآت

دورة المشاركة الحالية: **تحدٍّ ← انضمام ← وصف إثبات ← قيد المراجعة ← قبول أو رفض**. قبول إثبات معلّق يضيف XP والنقاط والساعات المحددة للتحدي مرة واحدة؛ الرفض لا يمنحها. هذه العمليات تحدث في الحالة المحلية للمتصفح.

- المستوى: `⌊√(XP / 100)⌋ + 1`.
- الفئات بحسب XP: برونزي من 0، فضي من 1500، ذهبي من 4000، بلاتيني من 9000.
- الأوسمة مرتبطة ببلوغ أعداد المبادرات المقبولة: 1 و3 و5 و7 و10 و20.
- استبدال المكافأة يخصم تكلفتها من النقاط ويرفض إذا كان الرصيد غير كافٍ.
- هذه الأرقام لا تمثل ساعات أو إنجازات موثقة في نظام مركزي حاليًا، ولا تُزامن بين الأجهزة أو حسابات المشرفين.

## 9. التطبيق القابل للتثبيت والعمل دون اتصال

يوجد ملف تعريف PWA وأيقونات مشتقة من الشعار الرسمي `public/logo.png`، مع عامل خدمة عبر `vite-plugin-pwa`. يمكن استخدام خيار التثبيت في الإعدادات عندما يدعمه المتصفح؛ على بعض الأجهزة يلزم التثبيت من قائمة المتصفح.

عامل الخدمة لا يُسجّل في التطوير أو المعاينة. في النسخة المنشورة يستخدم NetworkFirst للصفحات وCacheFirst للملفات المهيأة، ويمكن تعطيله بالمعامل `?sw=off`. هذا لا يضمن عمل جميع الصفحات دون اتصال: الدخول، حفظ التسجيل، رفع البطاقة، فحص AI والحذف تتطلب الإنترنت. ليس التطبيق تطبيقًا أصليًا منشورًا في متجر، بل تطبيق ويب قابل للتثبيت.

## 10. الهوية واللغات

الهوية: الأخضر الغابي `#145C43`، الزمردي `#20A675`، النعناعي `#DDF5E9`، الذهبي `#F5A623`، الخلفية `#F7F9F6`، والدرجات الداكنة `#101B16` و`#17251F`. الخطوط Cairo وTajawal، والشعار الرسمي صورة مستقلة. تُقص صورة الحساب بطريقة العرض دون تغيير الصورة الأصلية. دعم اللغات موجود، لكن بعض النصوص الجديدة مكتوبة بالعربية مباشرة وقد لا تكون مترجمة بالكامل.

## 11. دليل المشروع للمطور

- واجهة React مع TanStack Start وTanStack Router، وتصميم Tailwind CSS ومكونات الواجهة الموجودة بالمشروع.
- الصفحات في `src/routes`؛ حالة النشاط التجريبية في `src/lib/store.tsx` وبيانات العرض في `src/lib/data.ts`.
- فحص الهوية في `src/lib/idcard.functions.ts`، والتسجيل في `src/routes/register.tsx`، والخصوصية في `src/routes/settings.tsx`.
- صور وأيقونات التطبيق ضمن أصول المشروع. لا تضع مفاتيح خاصة في الواجهة أو README، ولا تجعل صور الهوية عامة.
- إعداد اتصال Lovable Cloud تديره بيئة المشروع؛ نسخ الملفات وحدها لا ينشئ تلقائيًا الجداول والسياسات ومساحة التخزين وإعدادات الدخول في بيئة جديدة.

```bash
bun install
bun run dev
bun run test
bun run build
```

هذه أوامر تشغيل واختبار وبناء المشروع في بيئة تطوير مستقلة؛ لا تثبت بمفردها صحة التسجيل أو أمن البيانات. الاختبارات المحلية تشمل سلوك الحالة التجريبية والتنقل، وليست شهادة نجاح لدورة بيانات الهوية.

## 12. متطلبات الإطلاق الحقيقي

قبل تقديم المنصة كنظام تطوع إنتاجي كامل يلزم:

1. اختبار إنشاء الحساب وتأكيد البريد والدخول ومزودي الدخول الفعليين.
2. اختبار الفحص بصورة اختبار غير حساسة، ثم الحفظ واسترجاع التسجيل، مع حالات انقطاع الشبكة وفشل الرفع.
3. التحقق من عدم قدرة حساب آخر على قراءة التسجيل أو صورة البطاقة، ومن إزالة الصورة فعلًا عند الحذف.
4. نقل التحديات والمشاركات والترتيب والنقاط والمكافآت إلى بيانات مشتركة، وتأمين صلاحيات المشرفين وعمليات احتساب الرصيد.
5. تحديد سياسة الموافقة والاحتفاظ ومعالجة بيانات الهوية لدى مزود AI، وتنفيذ ضوابط الحذف والفحص الصارم.
6. مراجعة كل صورة ولاية ومصدرها وحقوق استخدامها، وتجربة الهاتف واللغات والتثبيت والعمل دون اتصال في النسخة المنشورة.

**الخلاصة:** المنصة تجمع تجربة تطوع مكتملة بصريًا مع تسجيل متصل فعليًا بالخدمة وفحص هوية مساعد؛ النشاط الاجتماعي والتلعيب والإشراف لا يزال تجريبيًا، ولا ينبغي وصف التطبيق كله بأنه إنتاجي مكتمل قبل معالجة الحدود السابقة.
