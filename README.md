# إنجاز | INJAZ — إنجاز الأثر

> خطوة منك... أثر في مجتمعك

منصة تطوع جزائرية بتجربة تطبيق أصلي (PWA)، بتصميم زجاجي فاخر، عربية أولاً (RTL) مع الفرنسية والإنجليزية.

## الشاشات

| الشاشة | المسار | الوصف |
| --- | --- | --- |
| الرئيسية | `/` | ترحيب، بطاقة "رصيد الأثر" الخضراء مع اختصارات (التحديات، المكافآت، الخريطة، الإشراف)، مؤشرات (الساعات، المبادرات، الترتيب)، وتحديات مميزة مع أقراص تصنيف. |
| التحديات | `/challenges` | تبويب (الكل / المنضم إليها)، بحث، تصفية حسب التصنيف، وورقة سفلية للانضمام وإرسال إثبات الأثر. |
| خريطة الأثر | `/map` | خريطة الجزائر بـ58 ولاية، دبابيس ملونة حسب التصنيف، كبسولات إحصاء زجاجية عائمة في الأعلى، شريط تحكم سفلي (فلاتر، قريبة، زر الاكتشاف المتوهج، وطني، موقعي)، سحب وتكبير، وبطاقة الولاية المحددة. |
| المتصدرون | `/leaderboard` | منصة تتويج للثلاثة الأوائل وقائمة ترتيب، وطنياً أو على مستوى ولايتك. |
| حسابي | `/profile` | بطاقة داكنة: الصورة، الساعات، المبادرات المنجزة، المستوى، الفئة، الترتيب الوطني؛ بطاقات زجاجية (التقدم، XP، الأثر المجتمعي)، الأوسمة، وسجل المساهمات. |
| المكافآت | `/rewards` | فئة ذهبية بشارة سداسية، تبويبات اكسب/استخدم/امتيازات، كتالوج استبدال النقاط. |
| الإعدادات | `/settings` | **المكان الوحيد** لتبديل اللغة (عربي/فرنسي/إنجليزي)، الوضع الليلي، تثبيت التطبيق، إعادة تعيين البيانات. |
| الإشراف | `/admin` | مراجعة إثباتات الأثر (قبول/رفض يمنح XP والنقاط والساعات)، ونظرة على التحديات. |

## التنقل
- شريط سفلي زجاجي عائم بخمس وجهات، مع تجويف منحوت متحرك ودائرة نشطة عائمة.
- لا توجد قائمة همبرغر ولا شريط جانبي ولا شريط تنقل علوي — في كل الأجهزة.

## الأنظمة
- **التلعيب:** المستوى = ⌊√(XP/100)⌋ + 1؛ الفئات: برونزي (0)، فضي (1500)، ذهبي (4000)، بلاتيني (9000).
- **الأوسمة:** تُفتح بعدد المبادرات المقبولة (1، 3، 5، 7، 10، 20).
- **الإثبات:** المتطوع يرسل وصفاً ← "قيد المراجعة" ← المشرف يقبل (يُضاف XP والنقاط والساعات مرة واحدة) أو يرفض.
- **المكافآت:** الاستبدال يخصم التكلفة ويُرفض إن كانت النقاط غير كافية.
- **البيانات:** محفوظة محلياً في المتصفح (نسخة تجريبية). يمكن ربطها لاحقاً بقاعدة بيانات وحسابات مستخدمين.

## PWA
- `public/manifest.webmanifest` + أيقونات من الشعار الرسمي (`public/logo.png`).
- عامل خدمة عبر `vite-plugin-pwa` (الصفحات NetworkFirst، الملفات CacheFirst)، لا يُسجَّل في المعاينة أو التطوير — يعمل العمل دون اتصال في النسخة المنشورة فقط. أضف `?sw=off` لإلغائه.
- زر "تثبيت التطبيق" في الإعدادات، ضغط لمسي `press`، ودعم المناطق الآمنة.
